# How to:


**When you want to change the background or colors with GitHub Copilot:**
1. Save your work and close the project in Power BI Desktop before changing its files in Visual Studio Code
2. Open Copilot Chat in Visual Studio Code and ask Copilot to make the changes. Include the page or visual name and the color you want. For example:

   ```text
   Change the background of the report page "Page 1" to light blue (#E6F3FF).
   Only change that page and keep the existing visuals.
   ```

   ```text
   Change the colors of the bar chart on "Page 1" to dark blue (#003366)
   and light blue (#66B2FF). Keep the existing data and layout.
   ```

3. Replace the example page or visual name with the name used in your report
4. If Copilot proposes changes, review and accept only the changes you want. If it only provides instructions, ask it to apply the changes to the project files
5. Reopen `PBITest.pbip` in Power BI Desktop and check that the report opens and looks as expected. Check all affected pages and visuals
6. If the result is not correct, ask Copilot to adjust it or change the formatting in Power BI Desktop
